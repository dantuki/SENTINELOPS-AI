# Evidence provenance and retrieval trace

Authority flows as: isolated runner → trace-run UUID → Product API request → persisted retrieval event → retrieved chunk → document/source lineage → evidence manifest → structured model claims and citation aliases → evaluator verification. The API owns canonical chunk identity, rank, score, scope, and the SHA-256 of exact UTF-8 content. `E<n>` is only a per-request alias; the model cannot authoritatively select canonical IDs or support status.

The runner gives the evaluator a trace UUID distinct from its container run ID. Before cleanup, it uses the temporary database pool to re-read the trace header, ranked items, chunk bytes/hash, project, document/source relationship and statuses. The runner constructs the final evaluation report from that query result and the same-run response; it does not trust metrics emitted by the evaluator. `passed` requires verified trace provenance, complete measured retrieval/answer coverage, supported claim-to-evidence mappings, valid citations, no deterministic factuality violation or ground-truth leakage, successful evaluator exit, and verified cleanup.

The trace is application-append-only. No database immutability guarantee is claimed because deployment privileges and triggers have not been inspected. A matching SHA-256 proves byte equality, not the authenticity or truth of the underlying source. General project context is retained but does not count as incident-specific evidence. Coverage, contradiction, and factuality checks are deterministic INC-001 heuristics, not a universal semantic evaluator.

Local validation: API typecheck and build passed; 132 API tests passed, including mocked atomic trace persistence, stored lineage/scope/hash verification, report recomputation, and rejection of altered metrics. The read-only preflight found Ollama and both configured model names, but Docker and the local PostgreSQL image were unavailable and the orchestrator virtual environment was absent. No container, migration, PostgreSQL query, inference, or INC-001 evaluation was run. Real PostgreSQL/Ollama/RAG validation and the Reliability Gate remain pending.
